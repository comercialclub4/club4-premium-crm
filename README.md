# Club4 Premium CRM

CRM web app for Club4 Premium, built with Next.js, TypeScript, Tailwind CSS and Supabase.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase Auth + Postgres

## Supabase

Project: `Club4 Premium`
Region: `sa-east-1`

Copy `.env.example` to `.env.local` and add the publishable Supabase key before running locally.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.
